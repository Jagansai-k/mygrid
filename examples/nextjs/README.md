# Next.js App Router example

The page is a Server Component. It reads `@inno-grid/mygrid-core` on the server and renders `MyGrid` from `@inno-grid/mygrid-react`. The React package entry starts with `'use client'`, so the mount stays on the client boundary.

```bash
pnpm dev:example-nextjs
```

The dev server uses port 4186.
