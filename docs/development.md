# Development

## Workspace

`pnpm-workspace.yaml` includes `packages/*`, `apps/*`, and `examples/*`. Shared dependency versions live in the `catalog`. Internal packages depend on each other with `workspace:*`.

Turborepo tasks:

| Task              | Order                                                                     |
| ----------------- | ------------------------------------------------------------------------- |
| `build`           | Dependent packages build first. Outputs: `dist`, `.next`.                 |
| `typecheck`       | Dependent packages build first, so consumers see generated `.d.ts` files. |
| `test`            | Dependent packages build first. Vitest then runs inside the package.      |
| `dev`             | Dependent packages build first, then the dev server stays up.             |
| `build-storybook` | Dependent packages build first, then Storybook writes `storybook-static`. |
| `clean`           | Deletes `dist` in each library that defines the script. Not cached.       |

The React package tests import `@inno-grid/mygrid-core` through its package export, which points at `dist`. That is why tests wait for the core build.

## Checks

```bash
pnpm check
```

runs, in order:

1. `prettier --check`
2. `turbo run build`, so ESLint can see the generated declaration files
3. `eslint .`
4. `turbo run typecheck`
5. `pnpm test`, which builds the three libraries, runs Vitest, and imports the built packages
6. `turbo run build-storybook`
7. `node scripts/check-foundation.mjs`
8. `pnpm --filter playground verify`

Steps 5 and 8 import the built packages from Node. The import checks the client directive, the core bundle, the React package's dependency on core, every theme CSS export, and the declaration files next to each JavaScript entry. The playground file `src/package-consumer.ts` is part of `pnpm typecheck` and imports the same entry points, including the CSS.

Playwright is not inside `pnpm check` because it needs a browser install:

```bash
pnpm exec playwright install chromium
pnpm test:e2e
```

`pnpm test:e2e` builds the playground, serves `vite preview` on port 4183, and runs `e2e/playground.spec.ts`.

## Formatting and lint

Prettier uses single quotes, semicolons, a trailing comma where valid, and a print width of 100. `examples/nextjs/next-env.d.ts` is generated by Next.js and is left out of Prettier. ESLint is type-aware (`strictTypeChecked` and `stylisticTypeChecked`) and rejects `any`. React files also run `eslint-plugin-react` and `eslint-plugin-react-hooks`.

The two React entry files turn off `@typescript-eslint/no-unused-expressions` so the `'use client'` directive can stay the first statement.

## CI

`.github/workflows/ci.yml` installs with a frozen lockfile, runs `pnpm check`, installs Chromium, and runs `pnpm test:e2e`. The workflow is ready for the private GitHub repository. It does not publish packages.
